Defer & Async Scripts

Both attributes avoid blocking HTML parsing while an external script downloads, but their execution timing and ordering differ.

Async script

Executes as soon as its download is ready. It may run before or after HTML parsing completes.

Deferred script

Executes after HTML parsing and before the DOMContentLoaded event.

What is the difference?

  • defer preserves document order among deferred scripts and waits until parsing is complete.
  • async runs as soon as it is ready; execution order is not guaranteed.
  • Use defer for scripts that depend on the page DOM or on other scripts in order.
  • Use async for independent scripts that do not rely on a particular execution order.
