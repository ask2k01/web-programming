Lighthouse Accessibility Audit

Week 9_1 homework: improve page landmarks, heading structure, keyboard access, and readable contrast.

Audit findings and fixes

  • Main landmark: place the page's primary content in one semantic <main id="main-content">.
  • Navigation landmark: use <nav aria-label="Course navigation"> for the course links.
  • Decorative SVG: use aria-hidden="true" and focusable="false" when an icon adds no information.
  • Heading structure: provide one descriptive <h1>, followed by section <h2> headings.
  • Keyboard bypass: add a visible-on-focus skip link that targets the main landmark.
  • Text contrast: this page uses #475569 for muted text on white rather than the lighter #94a3b8, which does not provide 7:1 contrast on white.

Semantic page pattern

The companion course page applies these fixes. Its key structure is:

<a class="skip-link" href="#main-content">Skip to main content</a> <nav aria-label="Course navigation">...</nav> <main id="main-content"> <section aria-labelledby="topics-heading"> <h2 id="topics-heading">Lecture Topics</h2> </section> </main>

Verification checklist

  • Tab to the first link and confirm the skip link becomes visible.
  • Activate it and confirm focus moves to the main content.
  • Inspect the accessibility tree for named navigation, main, and sections.
  • Run Lighthouse in the browser to record actual results. Scores depend on the browser and run; no score is claimed here.
