Component code

function PlayerScore({ name, score, onIncrement, onDecrement }) {
  return (
    <div>
      <h3>{name}: {score}</h3>
      <button onClick={onDecrement}>−</button>
      <button onClick={onIncrement}>+</button>
    </div>
  );
}

function ScoreBoard() {
  const [p1, setP1] = useState(0);
  const [p2, setP2] = useState(0);

  return (
    <div>
      <PlayerScore name="Player 1" score={p1}
        onIncrement={() => setP1(p => p + 1)}
        onDecrement={() => setP1(p => p - 1)} />
      <PlayerScore name="Player 2" score={p2}
        onIncrement={() => setP2(p => p + 1)}
        onDecrement={() => setP2(p => p - 1)} />
      <h2>Total: {p1 + p2}</h2>
    </div>
  );
}

useState cheat sheet

Common state updates and the rules to remember when using Hooks.

Basic syntax

const [val, setVal] = useState(init);

Update a primitive

setCount(count + 1);
setCount(prev => prev + 1);

Update an object

setUser({ ...user, age: 21 });

Copy existing fields first, then override the value you want to change.

Add or remove array items

setItems(prev => [...prev, newItem]);
setItems(prev => prev.filter(item => item.id !== id));

Toggle a boolean

setIsOpen(prev => !prev);

Rules of Hooks

  • Call Hooks at the top level.
  • Call Hooks from React function components or custom Hooks.
  • Do not call Hooks in loops, conditions, or callbacks.

Lifting state up

The parent owns shared state and passes values and update callbacks to its children through props.
