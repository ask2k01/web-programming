How to run the audit

  1. Open the page you want to measure in Chrome.
  2. Open DevTools, select Lighthouse, and choose the Performance category and mobile or desktop mode.
  3. Run the audit before making changes and record the score and metrics above.
  4. Apply optimizations, run the same audit again, and record the after values.
  5. Keep the device mode, browser, network settings, and page content consistent for a fair comparison.
